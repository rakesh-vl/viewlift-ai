# Viewlift AI developer documentation

Viewlift AI is a local debug console for iOS and tvOS apps. It runs on your Mac and combines:

- an HTTP/HTTPS/WebSocket inspection proxy (mitmproxy),
- a TLS-pinned receiver for the `ViewliftNetworkCapture` Swift SDK,
- simulator and physical-device log streaming,
- an on-device debug bridge (UI, memory, storage, performance, OTT state),
- an MCP server so coding agents can query and drive the same data.

Everything binds to loopback by default, sensitive data is encrypted at rest, and every mutating action is opt-in.

## Glossary

- **Flow**: one captured HTTP exchange (request, response, timing, optional WebSocket frames). Stored as a `FlowRecord` with a `source` of `Proxy` or `SDK`.
- **client_id**: identifier of one app install, generated by the SDK and stored in the app's `UserDefaults`. Every SDK flow, SDK log and debug event carries it.
- **device_key**: groups apps that run on the same device. It is the simulator UDID on a simulator, or `vendor:<identifierForVendor>` on hardware.
- **device_hint**: hash of model, OS version, and boot time. Physical apps from different vendors share it until reboot. Empty on simulators.
- **Supersede**: when an app is reinstalled it gets a new `client_id`. The console marks the older id with the same `device_key` and `bundle_id` as superseded.
- **Allowlist**: hosts whose TLS traffic the proxy may decrypt. Empty means deny all; non-allowlisted hosts are tunnelled untouched.
- **Redaction**: replacing sensitive header and JSON values with `[REDACTED]` before storage, display and export.
- **Reveal**: an in-memory cache of raw (unredacted) flow data, unlocked per console process with a token. Needed for replay and raw viewing.
- **Pairing token**: a one-use, five-minute token that the SDK exchanges for a one-hour session token on the ingest receiver.
- **Debug bridge**: the SDK loop that registers the app, polls the console for commands and posts results back.
- **Mutating command**: a debug command that changes app state (for example `storage.file_write`). It needs an explicit confirmation.
