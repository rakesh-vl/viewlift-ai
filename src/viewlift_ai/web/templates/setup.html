iPhone

  1. Join the same Wi-Fi as this Mac. Select the LAN IP above, enable LAN bind, Apply. Do not use 127.0.0.1 on the phone.
  2. Download the CA profile in Safari on the iPhone. It contains only the certificate. A global HTTP proxy payload installs only on a supervised device, so this profile does not include one.
  3. Settings → General → VPN & Device Management → install the profile. Ignore the “Not Signed” warning.
  4. Settings → Wi-Fi → the network’s info button → Configure Proxy → Manual. Server is this Mac’s LAN IP. Port is the proxy port. Add the session basic-auth credentials if LAN bind is on.
  5. Settings → General → About → Certificate Trust Settings → enable full trust for the Viewlift AI / mitmproxy CA.
  6. When finished: turn off the Wi-Fi proxy, remove the configuration profile, and disable full trust / delete the certificate.

Apple TV

  1. Settings → Network → Wi-Fi → HTTP Proxy → Manual. Enter the selected LAN IP/port and basic-auth credentials from this page.
  2. Install the CA with a configuration profile via Apple Configurator (tvOS has no Safari profile install path like iPhone).
  3. Trust UI on tvOS is limited. Do not expect iPhone-parity Certificate Trust Settings.
  4. Certificate pinning: pinned builds will not decrypt. Failed handshakes appear as TLS failed (likely certificate pinning). This tool does not bypass pinning.
