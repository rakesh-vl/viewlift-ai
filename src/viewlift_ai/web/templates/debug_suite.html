    Hangs and crashes

    A crash appears here as it happens. Each card says in plain words what failed, shows the code at the crash line, the likely cause, and where to fix it. Below that are the steps that led there, a timeline you can click to jump in the replay video, the last requests, console lines, the environment, and the whole stack as file and line. The replay is the last ten seconds of the screen with taps drawn; it uploads on the app's next launch and can be downloaded. Copy for AI copies a markdown brief an agent can fix the crash from. File and line need the app's dSYM on this Mac, which a Debug build from Xcode provides. If Xcode is paused at the crash, continue the app so it can report. A hang is a main-thread stall over 400 ms. Each hang card shows the screen class, a screenshot from when the UI recovered, taps and scrolls before the stall, console lines, and the stack. Click the screenshot to enlarge it. Copy report for a bug note.
