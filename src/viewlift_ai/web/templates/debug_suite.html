Leak tracker and memory graph

Not tracking

Every view controller is tracked from viewDidLoad with the stack that created it. A screen still alive 3 seconds after it closes is a leak. With live tracking on, the app also records a small screen replay with your taps, so each leak comes with the steps to reproduce it, the class, its creation stack, what still holds it, and retain cycle candidates. Register other objects, such as view models, with MemoryDebugService.shared.track(_:).
